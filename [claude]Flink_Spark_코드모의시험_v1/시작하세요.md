2026-11-23 5회차 월말평가(코드베이스 Quest형 + 서술형) 대비 예상문제. 실제 시험지가 아닙니다.

## 순서
1. 환경: `pip install -r problem/requirements.txt` (Java 17 필요). Docker·클러스터 불필요.
2. `시험지.md` 읽기 → `problem/README.md`의 표대로 각 `problemN/`에서 `python 파일.py`
3. 채점: `정답_해설/정답해설.md` (정답 파일은 `정답_해설/problem/`)
4. `출처대응표.md`(실습·강의 근거), `검증보고서.md`(29/29 실행 확인, 확인 못 한 것)

## 형식
4회차(Docker & Kafka) 실제 시험과 같은 구조: 번호 빈칸 `___N___`(Q1·Q2) → 실행·캡처(Q3) → 틀 제공 코드 작성(Q4) → TODO + `raise NotImplementedError`(Q5~Q7, 함정 1개씩) → 서술형 3×5(Q8).

## 파일
- `problem.zip`: 응시용만(정답 없음)
- `정답_해설/_build/`: 생성기 `build.py`, 검증기 `verify.py`, 템플릿, 검증 로그. 템플릿 수정 후 `python build.py`
