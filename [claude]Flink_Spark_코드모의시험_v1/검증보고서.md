## 환경 (공지 재현)
- Docker 이미지 `fsenv:1`: `eclipse-temurin:17-jdk-noble`(Ubuntu 24.04, **OpenJDK 17.0.21**) + **Python 3.12.3** venv + `pip install -r requirements.txt`
- 설치 결과: **apache-flink 2.2.1**, **pyspark 3.5.4**, apache-flink-libraries 2.2.1, py4j 0.10.9.7, pandas 2.2.3, numpy 2.1.3 → `261123flink-spark시험/requirements.txt` 한 파일로 설치되는 것을 확인
- 클러스터·Docker Compose 없이 각 `problemN/`에서 `python 파일.py`로 실행 (Docker는 깨끗한 환경을 만드는 용도로만 사용)

## 방법
- `정답_해설/_build/build.py`: 템플릿 하나(`⟪응시용‖정답⟫`)로 `problem/`(응시용)과 `정답_해설/problem/`(정답)을 함께 생성 → 문제·정답의 파일명·데이터·출력 코드가 어긋나지 않음
- `정답_해설/_build/verify.py`: 정답을 실행해 기대 출력과 대조하고, 응시용이 빈칸·`raise`로 실패하는지, 함정 코드가 실제로 틀린 결과를 내는지 확인
- Q3는 `q3_ui_probe.py`가 Spark UI REST API(`/api/v1/applications/<id>/jobs`)로 Enter 전후 Job 수를 확인
- 로그: `정답_해설/_build/검증로그/verify_run1.txt`(전체), `verify_run2_p3p4p6.txt`(재검증)

## 검증 중 반영한 것
- Q5 출력 순서가 실측에서 `s1 4999, s2 2000, s2 9999, s1 5000, …`였다 → 시험지 예시를 실측 순서로 바꾸고 "순서는 달라도 됨"을 유지
- Q3에서 터미널에 찍히는 UI 주소가 컨테이너/컴퓨터 이름으로 나왔다 → 시험지에 "브라우저는 localhost:4040, 포트가 바뀌면 출력된 포트 사용" 안내 추가
- Q6 해설의 "형 변환 없이 sum하면 double" 주장 → `19000.0`으로 실측 확인

## 확인하지 못한 것 / 가정
- **실제 WSL 화면**: 실행은 Linux 컨테이너에서 했다. WSL 우분투에서도 같은 명령이지만 직접 실행·캡처하지는 않았다. Spark UI 화면 캡처는 REST API 값으로 대신 확인했다.
- **Python 버전**: 공지에는 Python 버전이 없다. 지난 시험 공지(Python 3.12)를 따랐다. 실습 tip은 Python 3.10/3.11 기준이었다.
- **실제 시험 형식**: 배점·문항 수·캡처 규칙은 4회차 시험지를 따른 가정이다. 공지의 "Quest형"이 이와 같은 형식인지는 확인되지 않았다.
- 강의 PDF는 대부분 이미지라 1109 p2~9, 1105 p15~18만 이미지로 직접 읽었다. 나머지는 사용자 메모·실습·수업 코드로 범위를 판단했다.
- Q8 서술형은 실행 검증 대상이 아니다. 모범 답안은 1109 강의 내용에 맞춰 작성했다.
