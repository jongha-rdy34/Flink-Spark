## 검증 범위

- 응시용과 정답 Python 구문, 모듈·입력 경로, requirements.txt 두 버전, 두 ZIP의 분리 상태를 검사합니다.
- 공개 및 대체 입력의 예상 결과 13건을 표준 라이브러리로 독립 검산합니다. Q07의 정답 SQL은 SQLite에서도 실행해 LEFT JOIN 조건, NULL·0 처리와 동률 정렬을 대조합니다. 이는 Spark SQL 실행을 대신하지 않습니다.
- 현재 Windows 터미널에서 java를 찾지 못했고 PySpark·PyFlink 패키지는 설치되어 있지 않았습니다. WSL 조회는 권한 오류를 반환했습니다. 제공 검사기로 Q03·Q07의 실제 구동을 시도했으나 각각 pyflink와 pyspark import 단계에서 종료되어 로컬 JVM 통합 검증은 미완료입니다. 제공 verify.py를 공지 버전과 JDK가 준비된 환경에서 실행하면 두 엔진의 실제 결과를 검사합니다. 체크포인트 복원이나 외부 싱크는 모의시험의 실행 검증 범위 밖입니다.

문제지 PDF는 5쪽을 모두 렌더링해 검토했고, 여덟 문항 제목이 빠짐없이 포함된 것을 확인했습니다.
