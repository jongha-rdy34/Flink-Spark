| 학습 방향  
거래 유형별 금액을 집계하려면 데이터 구조와 그룹화 기준을 올바르게 지정하는 것이 중요하다. 
본 과제에서는 CSV에서 유형과 금액을 읽어 전처리한 후, 튜플 스트림을 구성하여 누적 집계를 수행한다. 
유형별 합계: key_by()로 거래 유형을 선택하고 sum()으로 금액을 누적하여 각 유형의 중간 결과와 최종 합계를 확인한다.  

요구사항
1.    실행 환경 생성
   StreamExecutionEnvironment.get_execution_environment()를 사용하여 실행 환경을 생성하세요. 클래스와 메서드의 빈칸을 채우고 데이터 읽기부터 집계 결과 출력까지 연결하세요.

2.    CSV 데이터 불러오기 및 전처리
   read_csv()를 사용하여 제공된 data/data.csv를 읽고 transaction_type과 amount 컬럼을 선택하세요. dropna()와 values.tolist()로 결측값을 제거하고 리스트로 변환하세요.파일 경로는 제공된 코드처럼 Python 파일 위치를 기준으로 계산하세요. 거래 유형은 문자열, 거래 금액은 실수이며 튜플에서 두 필드의 순서를 유지해야 합니다.

3.    데이터 스트림 생성
   환경 생성 클래스와 메서드, from_collection() 및 type_info 빈칸을 채우세요. Types.TUPLE([Types.STRING(), Types.FLOAT()])으로 입력 구조를 지정하세요.

4.    거래 유형별 금액 집계
   그룹화 메서드와 키 선택식, 합산 메서드와 필드 인덱스의 빈칸을 채우세요. transaction_type을 키로 사용하고 amount의 값을 유형별로 누적하세요.

5.    프로그램 실행
   제공된 execute_and_collect()로 작업을 실행하고, 수집한 결과를 반복문과 print()로 출력하세요. 입력 데이터의 처리 결과를 확인하세요.
