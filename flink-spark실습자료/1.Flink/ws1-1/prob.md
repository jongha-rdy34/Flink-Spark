문제
| 학습 방향  
스트리밍 프로그램을 작성할 때는 실행 환경과 데이터 입력을 올바르게 구성하는 것이 중요하다.
본 실습에서는 문자열 목록을 PyFlink 스트림으로 변환한 후, 작업을 실행하여 설치 환경과 기본 처리 흐름을 확인한다.
문자열 스트림: from_collection()으로 Hello, Flink, World를 전달하고 수집한 결과를 순서대로 출력한다.  

요구사항
1.    실행 환경 생성   
   StreamExecutionEnvironment의 실행 환경 생성 메서드를 완성하고, set_parallelism(1)을 사용하여 병렬성을 1로 지정하세요.

2.    입력 데이터 준비
   제공된 문자열 목록 ["Hello", "Flink", "World"]를 입력으로 사용하세요. 문자열을 처리하는 간단한 작업으로 실행 환경을 확인합니다.목록의 각 요소를 하나의 데이터로 처리하고, 문자열 세 개가 각각 출력될 수 있도록 구성하세요.

3.    데이터 스트림 생성
   from_collection()의 빈칸을 채우고 Types.STRING()을 지정하여, 문자열 목록을 데이터 스트림으로 변환하세요.

4.    결과 수집 및 확인
   execute_and_collect()로 작업을 실행하고 반환된 결과를 반복문으로 순회하세요. 데이터 스트림을 정의하는 단계와 실행하는 단계를 구분하세요.

5.    프로그램 실행
   print()로 출력된 Hello, Flink, World를 확인하세요.
