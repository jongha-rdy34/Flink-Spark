| 학습 방향  
같은 데이터라도 창의 길이와 이동 방식에 따라 집계 결과가 달라질 수 있다. 
본 과제에서는 동일한 사용자별 스트림에 두 종류의 이벤트 시간 창을 적용하고 결과를 나란히 비교한다.
윈도우 비교: 5초 텀블링 창과 10초·5초 슬라이딩 창을 구성하여 합계를 계산하고, 접두사가 있는 출력을 병합하여 차이를 확인한다.  

요구사항
1.    실행 환경 생성
   StreamExecutionEnvironment.get_execution_environment()를 사용하여 실행 환경을 생성하세요. 제공된 병렬성 설정을 유지하고 입력부터 결과 출력까지의 처리 흐름을 구성하세요.

2.    사용자 데이터 및 이벤트 시각 준비
   제공된 A와 B의 이벤트 6개를 사용하세요. A의 (값, 시각)은 (2,1000), (3,3000), (5,7000)이며 B는 (4,2000), (1,7000), (6,9000)입니다.EventTimestampAssigner로 세 번째 필드의 시각을 지정하세요. no_watermarks() 설정을 유지하고, 유한 입력 종료 시 두 종류의 창 결과가 처리되는지 확인하세요.

3.    데이터 스트림 생성
   문자열·정수·긴 정수의 튜플 스트림에 이벤트 시각을 할당하세요. key_by()로 사용자별 그룹을 만든 뒤 동일한 keyed 스트림을 두 윈도우에 전달하세요.

4.    윈도우 집계 및 결과 병합
   제공된 시간 설정(텀블링 5초, 슬라이딩 길이 10초·간격 5초)을 유지하세요. 사용자별 그룹화 API와 두 윈도우 클래스를 선택하고, 각 reduce()에서 값의 합계를 계산하는 식을 완성하세요. TUMBLING과 SLIDING 접두사를 붙인 결과를 병합하는 API도 완성하세요.

5.    프로그램 실행
   제공된 execute_and_collect()로 작업을 실행하고, 수집한 결과를 반복문과 print()로 출력하세요. 입력 데이터의 처리 결과를 확인하세요.
