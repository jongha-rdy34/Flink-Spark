| 학습 방향  
뉴스에서 필요한 키워드를 추출하고 등장 횟수를 계산하는 과정은 텍스트 분석에 중요하다. 
본 실습에서는 CSV의 뉴스 문장을 읽어 전처리한 후, 금융 키워드만 선택하여 빈도를 집계한다.
키워드 집계: flat_map()과 filter()로 단어를 추출하고, key_by().sum(1)을 사용하여 동일한 키워드의 등장 횟수를 누적한다.  

요구사항
1.    실행 환경 생성
   StreamExecutionEnvironment의 실행 환경 생성 메서드를 완성하세요. 병렬성 설정 메서드와 인수의 빈칸을 채워 병렬성을 2로 지정하세요.

2.    CSV 데이터 불러오기 및 전처리
   Pandas의 read_csv()를 사용하여 제공된 data/data.csv의 news_text 컬럼을 읽으세요. dropna()와 tolist()를 통해 결측값을 제거하고 문자열 목록으로 변환하세요.문장은 공백으로 분리하고 각 단어를 소문자로 변환하세요. 금융 키워드 집합은 stock, market, investment, economy이며, 제공된 단어 처리 규칙을 유지하세요.

3.    데이터 스트림 생성
   from_collection()의 빈칸을 채워 문자열 스트림을 생성하고 Types.STRING()을 지정하세요. 실행 환경의 병렬성 설정 메서드와 값은 set_parallelism(2)로 완성하세요.

4.    키워드 추출 및 집계
   flat_map(), filter(), key_by()에 해당하는 빈칸을 채우세요. (단어, 1)로 펼친 데이터에서 금융 키워드를 선택하고 sum(1)로 단어별 등장 횟수를 누적하세요.

5.    프로그램 실행
   제공된 execute_and_collect()로 작업을 실행하고, 수집한 결과를 반복문과 print()로 출력하세요. 입력 데이터의 처리 결과를 확인하세요.
