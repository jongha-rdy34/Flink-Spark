| 학습 방향  
주문 데이터를 처리할 때는 유효한 입력을 선별한 후 금액을 계산하는 과정이 중요하다. 
본 실습에서는 제공된 주문 목록을 데이터 스트림으로 변환하고, 조건 검사와 금액 계산을 순서대로 수행한다.
주문 금액 처리: filter()로 단가와 수량이 양수인 주문을 선택한 뒤, map()으로 주문별 금액을 계산하여 결과를 출력한다.  

요구사항
1.    실행 환경 생성
   StreamExecutionEnvironment.get_execution_environment()를 사용하여 실행 환경을 생성하세요. 제공된 병렬성 설정을 유지하고 입력부터 결과 출력까지의 처리 흐름을 구성하세요.

2.    주문 데이터 준비
   제공된 orders 목록의 A, B, C, D 주문을 사용하세요. 각 튜플은 (주문 ID, 단가, 수량)이며, 입력의 필드 순서와 값을 유지하세요.단가와 수량이 모두 0보다 큰 경우만 유효한 주문으로 처리하세요. D 주문은 수량이 0이므로 결과에 포함되지 않아야 하며 다른 주문의 금액은 정상적으로 계산해야 합니다.

3.    데이터 스트림 생성
   실행 환경과 from_collection()의 빈칸을 채우세요. 주문 ID는 문자열, 단가와 수량은 정수인 튜플 타입으로 데이터 스트림을 구성하세요.

4.    주문 선택 및 금액 계산
   filter()와 map()에 해당하는 빈칸을 채우고, 단가와 수량을 곱하는 식을 작성하세요. 결과는 (주문 ID, 금액)의 문자열·정수 튜플로 구성하세요.

5.    프로그램 실행
   totals의 execute_and_collect() 빈칸을 채워 작업을 실행하고 결과를 터미널에 출력하세요. A, B, C의 금액이 표시되고 D가 제외되는지 확인하세요.
