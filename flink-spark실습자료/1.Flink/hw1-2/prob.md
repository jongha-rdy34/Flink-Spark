| 학습 방향  
상품별 판매 실적을 계산하려면 개별 거래 금액의 산출과 상품 기준 집계를 함께 수행해야 한다. 
본 과제에서는 수량과 단가를 가진 거래 데이터를 스트림으로 변환하여 상품별 누적 금액을 계산한다.
판매 금액 집계: map()으로 수량과 단가를 곱한 뒤, key_by()와 sum()을 사용하여 동일한 상품의 금액을 합산한다.  

요구사항
1.    실행 환경 생성
   StreamExecutionEnvironment.get_execution_environment()를 사용하여 실행 환경을 생성하세요. 제공된 병렬성 설정을 유지하고 입력부터 결과 출력까지의 처리 흐름을 구성하세요.

2.    상품 거래 데이터 준비
   제공된 (상품, 수량, 단가) 목록을 사용하세요. apple의 단가는 1000이고 banana의 단가는 500이며, 각 거래의 수량은 코드의 입력 값을 유지하세요.수량은 튜플의 1번 필드, 단가는 2번 필드입니다. 두 값을 곱하여 판매 금액을 계산하고, 상품 이름과 판매 금액만 가진 튜플로 변환하세요.

3.    데이터 스트림 생성
   from_collection()에서 문자열·정수·정수 타입을 사용하세요. map() 이후에는 상품 이름과 계산한 금액에 맞게 문자열·정수 타입을 유지하세요.

4.    상품별 금액 집계
   map()의 계산식과 sum()의 필드 인덱스 빈칸을 채우세요. 상품 이름으로 그룹화한 후 변환된 튜플의 금액을 누적하여 상품별 판매 합계를 구하세요.

5.    프로그램 실행
   제공된 execute_and_collect()로 작업을 실행하고, 수집한 결과를 반복문과 print()로 출력하세요. 입력 데이터의 처리 결과를 확인하세요.
