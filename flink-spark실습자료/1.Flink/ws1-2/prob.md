문제
| 학습 방향  
작업 코드를 작성하는 과정과 실행 환경에 제출하는 과정을 구분하는 것이 중요하다.
본 실습에서는 문자열 스트림을 처리하는 프로그램을 완성한 후, 같은 파일을 두 가지 방식으로 실행하여 결과를 비교한다.
실행 방식 비교: Python 명령과 Flink CLI를 사용하고, 제출 로그와 실제로 수집한 문자열 출력을 구분하여 확인한다.  

요구사항
1.    실행 환경 확인
   제공된 실행 환경 생성 코드를 확인하고 병렬성 1을 유지하세요. Python과 Flink CLI를 사용할 수 있는 실행 환경을 준비하세요.

2.    입력 데이터 준비
   Hello, Flink, World로 구성된 문자열 목록을 사용하세요. 두 실행 방식에서 같은 프로그램과 데이터를 사용합니다.문자열 타입은 Types.STRING()으로 지정하고, 입력 목록의 각 요소가 결과에 출력되도록 구성하세요.

3.    데이터 스트림 생성
   from_collection()의 빈칸을 채워 문자열 목록을 데이터 스트림으로 변환하세요.

4.    작업 실행 및 결과 수집
   execute_and_collect()의 빈칸을 채워 작업을 실행하고, 반환된 결과를 반복문으로 순회하면서 각 문자열을 출력하세요.

5.    실행 방식 비교
   Python 직접 실행과 Flink CLI 제출의 과정 및 출력 결과를 비교하세요.
