| 학습 방향  
정해진 입력 개수마다 결과를 출력하려면 시간 창과 별도로 발화 조건을 구성해야 한다. 
본 실습에서는 정수 데이터에 이상값 여부를 표시한 후, 사용자 정의 개수 트리거로 집계를 수행한다.
개수 기반 집계: Global Window에서 3건마다 합계와 이상값 포함 여부를 출력하고, 창과 카운터를 초기화하여 다음 데이터를 처리한다.  

요구사항
1.    실행 환경 생성
   StreamExecutionEnvironment.get_execution_environment()를 사용하여 실행 환경을 생성하세요. 제공된 병렬성 설정을 유지하고 입력부터 결과 출력까지의 처리 흐름을 구성하세요.

2.    입력 데이터 및 이상값 기준 준비
   제공된 정수 목록 [1, 3, 4, 9, 5, 7]을 사용하세요. map()에서 각 값이 8 이상인지 판별하고, 원래 값과 Boolean 표시를 가진 튜플을 만드세요.전체 입력을 3건씩 두 묶음으로 처리하세요. 각 묶음에서 값은 더하고 이상값 표시는 논리 OR로 결합하여, 하나라도 이상값이 있으면 True가 되도록 하세요.

3.    데이터 스트림 생성
   from_collection()의 정수 입력과 map()의 정수·Boolean 출력 타입을 유지하세요. window_all(GlobalWindows.create())로 전체 스트림을 하나의 창에 전달하세요.

4.    사용자 정의 트리거 집계
   건수가 임계치 이상인지 확인하는 조건과 FIRE_AND_PURGE 빈칸을 채우세요. 카운터 초기화 후 발화하고, reduce()에서 합계와 이상값 포함 여부를 반환하세요.

5.    프로그램 실행
   제공된 execute_and_collect()로 작업을 실행하고, 수집한 결과를 반복문과 print()로 출력하세요. 입력 데이터의 처리 결과를 확인하세요.
