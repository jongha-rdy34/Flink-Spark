문제
| 학습 방향  
같은 종류의 데이터를 묶어 수량을 계산하는 과정은 스트림 집계에서 중요하다. 
본 실습에서는 과일 이름과 수량을 가진 데이터를 입력한 후, 과일별 누적 수량을 계산하여 결과를 확인한다.키별 합계: key_by()로 과일을 구분하고 sum()으로 수량을 누적하여, 중간 결과와 각 과일의 마지막 합계를 비교한다.  

요구사항
1.    실행 환경 생성
   StreamExecutionEnvironment.get_execution_environment()를 사용하여 실행 환경을 생성하세요. 제공된 병렬성 설정을 유지하고 입력부터 결과 출력까지의 처리 흐름을 구성하세요.

2.    과일 데이터 준비
   제공된 (과일, 수량) 목록을 사용하세요. apple 1개, banana 1개, apple 1개, banana 2개가 입력되며, 같은 이름의 과일끼리 수량을 합산해야 합니다.튜플의 0번 필드는 과일 이름이고 1번 필드는 수량입니다. 키를 선택하는 인덱스와 실제로 값을 더할 필드의 인덱스를 구분하여 확인하세요.

3.    데이터 스트림 생성
   from_collection()을 사용하고 Types.TUPLE([Types.STRING(), Types.INT()])으로 (과일 이름, 수량) 형태의 데이터 스트림을 구성하세요.

4.    과일별 누적 집계
   key_by()의 키 선택식과 sum()의 인덱스 빈칸을 채우세요. 과일 이름으로 그룹화하고 수량을 합산하여, 과일별로 독립적인 누적 값이 계산되도록 하세요.

5.    프로그램 실행
   제공된 execute_and_collect()로 작업을 실행하고, 수집한 결과를 반복문과 print()로 출력하세요. 입력 데이터의 처리 결과를 확인하세요.
