| 학습 방향  
데이터 처리 결과와 함께 연산의 연결 구조를 이해하는 것이 중요하다. 
본 실습에서는 키별 합계 파이프라인을 구성한 후, 실행 계획을 조회하고 실제 작업 결과를 비교한다.
실행 계획 확인: get_execution_plan()으로 입력과 집계 연산의 구성을 확인하고, execute_and_collect()로 수집한 값과 역할을 구분한다. 

요구사항
1.    실행 환경 생성
   StreamExecutionEnvironment.get_execution_environment()를 사용하여 실행 환경을 생성하세요. 제공된 병렬성 설정을 유지하고 입력부터 결과 출력까지의 처리 흐름을 구성하세요.

2.    키와 값 데이터 준비
   제공된 입력 [("A", 1), ("B", 2), ("A", 3)]을 사용하세요. 첫 번째 필드는 그룹화 기준이며, 두 번째 필드는 키별로 누적할 정수 값입니다.동일한 A 키의 값은 하나의 합계로 누적되어야 하며 B 키의 값은 별도로 유지되어야 합니다. 각 키의 중간 결과와 마지막 누적 값을 구분하세요.

3.    데이터 스트림 생성
   from_collection()과 Types.TUPLE()을 사용하여 문자열 키와 정수 값의 스트림을 구성하고, sum()의 빈칸에 합산할 필드의 인덱스를 지정하세요.

4.    실행 계획 조회
   실행 환경에서 현재 작업의 실행 계획을 반환하는 메서드를 채우세요. DAG Execution Plan 출력에서 입력과 집계 연산의 구성을 확인하고 실제 데이터 출력과 구분하세요.

5.    프로그램 실행
   제공된 execute_and_collect()로 작업을 실행하고, 수집한 결과를 반복문과 print()로 출력하세요. 입력 데이터의 처리 결과를 확인하세요.
