문제
| 학습 방향  
스트림의 각 요소에 동일한 계산 규칙을 적용하는 것은 데이터 처리의 기본 과정이다. 
본 실습에서는 정수 목록을 데이터 스트림으로 구성한 후, map 연산을 사용하여 각 값을 두 배로 변환한다.
정수 변환: map()의 lambda 표현식으로 입력 값에 2를 곱하고, 입력과 출력의 개수 및 계산 결과를 비교하여 변환 동작을 확인한다.  

요구사항
1.    실행 환경 생성
   제공된 실행 환경 생성 코드를 확인하고 set_parallelism(1)을 유지하세요.

2.    입력 데이터 준비
   입력 목록 [1, 2, 3, 4, 5]를 사용하세요. 다섯 개의 정수 각각에 동일한 계산 규칙을 적용합니다.각 입력 값을 두 배로 변환하세요. 입력을 제외하거나 분해하지 않고 하나의 입력에서 하나의 출력을 생성해야 합니다.

3.    데이터 스트림 생성
   제공된 from_collection()과 Types.INT()를 확인하여 정수 타입의 데이터 스트림을 구성하세요.

4.    데이터 변환 처리
   map() 메서드와 lambda 식의 빈칸을 채우세요. x * 2를 사용하여 입력 값을 두 배로 만들고 output_type=Types.INT()를 유지하세요.

5.    프로그램 실행
   execute_and_collect()로 Map Example 작업을 실행하고 반복문으로 결과를 출력하세요. 2, 4, 6, 8, 10의 다섯 값이 출력되는지 확인하세요.
