| 학습 방향  
병렬 처리 환경에서도 같은 키의 데이터가 올바르게 집계되는지 확인하는 것이 중요하다. 
본 과제에서는 입력 값을 두 배로 변환한 후 키별 합계를 계산하고, 실행 계획을 함께 확인한다.
병렬 집계: 병렬성을 2로 지정한 실행 환경에서 map()과 key_by().sum()을 연결하여, 키별 누적 값과 연산 구성을 비교한다.  

요구사항
1.    실행 환경 생성
   StreamExecutionEnvironment.get_execution_environment()로 실행 환경을 생성하세요. set_parallelism()의 빈칸을 2로 채워 병렬 실행을 설정하세요.

2.    키와 값 데이터 준비
   제공된 입력 [("A", 10), ("B", 20), ("A", 30), ("B", 40)]을 사용하세요. 첫 번째 필드는 키이며, 두 번째 필드는 변환하고 누적할 정수 값입니다.키는 그대로 유지하고 각 값에 2를 곱하세요. A와 B의 누적 상태를 구분하며, 병렬 실행에 따라 서로 다른 키의 출력 순서가 달라질 수 있음을 확인하세요.

3.    데이터 스트림 생성
   from_collection()에서 문자열과 정수의 튜플 타입을 지정하세요. map()에서도 같은 출력 타입을 유지하고 값 필드를 두 배로 변환하는 식을 채우세요.

4.    키별 집계와 실행 계획
   key_by().sum(1)으로 변환된 값을 누적하고, 실행 계획을 반환하는 환경 메서드의 빈칸을 채우세요. 계획에 나타난 연산 구성과 키별 합계 결과를 비교하세요.

5.    프로그램 실행
   제공된 execute_and_collect()로 작업을 실행하고, 수집한 결과를 반복문과 print()로 출력하세요. 입력 데이터의 처리 결과를 확인하세요.
