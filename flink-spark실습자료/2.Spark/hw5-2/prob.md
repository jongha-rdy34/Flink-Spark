| 학습 방향  
●   상품 단가와 주문 수량을 키-값 RDD로 생성합니다.
●   상품 키로 두 RDD를 조인하고 주문별 금액을 구합니다.
●   상품별 합계와 전체 금액을 계산하고 조인에서 제외된 키를 확인합니다.  

요구사항
1.	상품 단가와 주문 수량 준비
    ○   단가 [(A,1000), (B,2000), (C ,3000)]와 
        주문 [(A,2), (B,1), (A,3), (C,2), (D,4)]를 사용하세요.
        상품 키는 문자열이며 각 RDD는 2개 파티션으로 생성하세요.
    ○   두 RDD의 전체 내용과 원본 주문 수를 출력하세요.

2.	상품 키를 기준으로 주문과 단가 연결
    ○   orders.join(prices)로 주문 수량과 단가를 연결하세요.
        같은 상품 의 주문이 여러 건이면 각 주문을 단가와 연결하세요.
    ○   조인 결과를 collect()한 뒤 Python sorted()로 정렬하여 출력하세요.
    ○   조인 결과의 각 원소가 (상품, (수량, 단가)) 구조인지 확인하세요.
    ○   조인 결과의 원소 수를 출력하세요.
    ○   단가 RDD에 없는 D의 주문이 결과에 포함되는지 확인하세요. 
    ○   원본 주문 5건과 조인 결과 4건을 비교하세요.
    ○   A의 주문 두 건이 조인 후에도 각각 유지되는지 확인하세요.
    ○   출력 순서 대신 키와 값의 내용을 기준으로 결과를 확인하세요.

3.	주문별 금액과 상품별 합계 계산
    ○   map()으로 (상품, 수량×단가)를 만들고 reduceByKey()로 상품별 주문 금액을 합산하세요.
    ○   주문별 금액과 상품별 합계를 키 순서로 출력하세요.

4.	전체 주문 금액과 계산 결과 출력
    ○   조인 결과의 원소 수를 출력하세요.○   상품별 합계를 키 순서로 출력하세요.
    ○   주문별 금액 RDD에서 map()으로 금액만 선택하고 sum()으로 전체 합계를 구하세요.○   전체 주문 금액을 출력하세요.
    ○   조인 결과·상품별 합계·전체 금액을 제출하고 D가 제외되는 이유를 설명하세요.
