| 학습 방향  
●   DataFrame의 컬럼별 데이터 유형을 확인하고 분석 목적에 맞는 데이터 유형으로 변환하는 과정을 실습합니다.
●   문자열 형태의 날짜 데이터를 날짜(Date)형으로 변환하고, 숫자 데이터의 문자열 유형을 정수(Integer)형으로 변환하여 분석에 적합한 형태로 변경합니다.  

요구사항
○ 주문 데이터의 원본 타입 확인  
    데이터: [    ("Alice", "25-12-2023", "3500"), ("Bob", "10-01-2024", "4500"), ("Charlie", "05-02-2024", "5000"), ("David", "15-03-2024", "6000")]   
    컬럼명: ["Customer", "OrderDate", "Price"]  
    제공된 데이터와 컬럼명으로 DataFrame을 생성하고 스키마를 출력하세요.

- Price와 OrderDate가 문자열인 원본 상태를 확인하세요.
- 가격을 숫자로 처리할 수 있도록 Price를 정수형 Price_Int로 변환하세요.
- 날짜 기준으로 처리할 수 있도록 OrderDate를 dd-MM-yyyy로 해석하여 날짜형 Order_Date_Format을 추가하세요.
- Price_Int가 정수형인지 확인하여 문자열 가격과 숫자 가격을 구분하세요.
- Order_Date_Format이 날짜형인지 확인하고 입력 일·월·연도가 올바르게 해석됐는지 비교하세요.
- 변환 후 전체 스키마와 데이터를 출력하여 원본 값과 변환 결과를 함께 확인하세요.
- 원본·변환 후 스키마와 최종 데이터를 제출하세요.
