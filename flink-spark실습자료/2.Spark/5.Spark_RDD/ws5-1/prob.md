 학습 방향
●   RDD 생성 및 변환을 다양한 예제를 통해 실습합니다.
●   각 변환 연산이 어떻게 동작하는지 이해하고, 지연 실행의 개념을 이해할 수 있도록 합니다.   

요구사항
○ 메모리 데이터의 RDD 변환
- 1~5를 RDD로 생성하고 출력하세요.
- 같은 원본에서 짝수 선택과 2배 변환을 각각 수행하여 결과를 확인하세요.

○ 외부 텍스트 입력 탐색
- data/test.txt를 RDD로 읽고 문장을 출력하세요.
- 메모리 목록과 파일 입력을 같은 RDD 연산으로 처리할 수 있도록 구성하세요.

○ 문장 선택과 단어 단위 변환
- Spark가 포함된 문장을 대소문자를 구분하여 선택하세요.
- 원본 문장을 공백으로 분리하고 flatMap으로 단어를 펼쳐 두 결과를 출력하세요.

○ 계산을 지연하는 변환 체인 구성
- 숫자를 2배로 변환하고 5보다 큰 값만 남기는 lazy_rdd를 정의하세요.
- 아직 collect()를 호출하지 않고 정의 완료 메시지를 출력하세요.

○ Action 전후의 실행 비교
- 제공된 입력 대기 중 Spark UI를 확인하고, 대기 후 lazy_rdd.collect()를 실행하세요.
- 출력 [6, 8, 10]과 Spark UI의 Job 변화를 확인하세요.
- 변환 정의와 실제 결과 계산이 수행되는 시점을 구분하세요.
